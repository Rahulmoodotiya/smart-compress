Resize Images Online

Resize images for websites, profiles, forms and sharing. SmartCompress offers percentage presets and custom dimensions, with an option to preserve the image's proportions.

Why resize?

An image with far more pixels than its display area may consume unnecessary storage and bandwidth. Resizing can reduce file size and make files easier to upload or share.

Use percentage presets

Choose a preset such as 25%, 50% or 75% to scale the original dimensions proportionally. This is a quick way to create a smaller version.

Set custom dimensions

Enter a width or height. With keep-ratio enabled, the other dimension is calculated to preserve the original proportions. Disabling the option allows independent dimensions, but may stretch the image.

Choose an output format

JPG works well for photographs. WebP can provide efficient size for supported workflows. PNG is useful for transparent images and lossless graphics.

Steps

Select image files, choose a resize preset or custom dimensions, select an output format and quality if supported, then compress and download. Keep the original for future edits.
