Website Image Optimization Checklist

Images can make a page more useful and visually engaging—but unnecessarily large files can slow loading, consume bandwidth and frustrate mobile visitors. Use this checklist before publishing images to your website.

1. Choose the right file format

  • JPEG/JPG: useful for photographs and complex images without transparency.
  • PNG: useful when sharp edges, graphics or transparency matter; often larger for photographs.
  • WebP: a modern option that often produces smaller files while retaining good visual quality.

Compare formats on the actual image rather than converting every file blindly. JPG guide · PNG guide · WebP guide

2. Resize to the display dimensions

  • Do not upload a huge original if the page only displays a small image.
  • Use dimensions appropriate to the layout and device.
  • Retain the aspect ratio unless a deliberate crop is needed.
  • For high-density displays, consider an appropriately sized larger variant rather than an excessively large original.

See our image resizing guide.

3. Compress before uploading

  • Start with a quality setting that keeps details and text acceptable.
  • Compare the compressed image with the original at actual display size.
  • Check fine details, gradients, faces, edges and text for artifacts.
  • Do not chase a tiny file size if the image becomes visibly damaged.

Learn how to reduce image size in KB.

4. Keep transparent images transparent

If a logo, icon or cutout needs transparency, verify that the chosen output format supports alpha transparency. Converting a transparent PNG to JPEG usually replaces transparent areas with a solid background. Check the result before using it.

5. Use descriptive file names and alternative text

  • Use short, descriptive file names that reflect the image naturally.
  • Write useful alt text when the image conveys information.
  • For decorative images, avoid adding unnecessary descriptions.
  • Do not stuff keywords into names or alt text.

6. Check the image in context

  • Preview on mobile and desktop.
  • Check that the image is not stretched, blurry or unexpectedly cropped.
  • Verify that colors and transparency appear correctly.
  • Ensure the image does not push important content out of view.

7. Optimize batches consistently

When preparing a group of images, use consistent dimensions and settings where appropriate. Review a few representative results before processing the full set, and keep original files as backups until you have verified the output.

8. Test page loading after publishing

Image compression is only one part of performance. Confirm that images are sized correctly in the page, avoid loading unnecessary assets, and test your pages on a real mobile connection as well as desktop.

Quick checklist

  • ☐ Correct format selected
  • ☐ Image dimensions match intended use
  • ☐ File compressed with acceptable quality
  • ☐ Transparency checked where needed
  • ☐ Descriptive file name and useful alt text
  • ☐ Mobile and desktop previews checked
  • ☐ Original file backed up until final verification
