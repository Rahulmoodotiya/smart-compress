How to Compress PNG Images

PNG is a lossless format commonly used for screenshots, logos, graphics and images with transparency. SmartCompress supports PNG input and output.

Important PNG facts

  • PNG is lossless; the quality slider does not reduce PNG file size.
  • Re-encoding may not make a PNG smaller. SmartCompress may retain the original when it would be larger.
  • PNG transparency is preserved when exporting PNG.
  • Converting PNG to JPG removes transparency and uses a white background.

How to process PNG

  1. Select PNG files on the compressor.
  2. Choose PNG to keep transparency, or WebP/JPG for smaller lossy output where appropriate.
  3. Resize if the image dimensions are larger than needed.
  4. Compress and inspect the output before downloading.

Which format should I choose?

Use PNG for graphics, screenshots, logos or transparency. For photographs, JPG or WebP can often produce smaller files.
