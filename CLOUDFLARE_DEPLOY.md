# Cloudflare Pages deployment (after QA)

1. Push this folder's files to the GitHub repository's main branch.
2. In Cloudflare Pages, create a project and connect the GitHub repository.
3. Framework preset: None / static site.
4. Build command: leave empty.
5. Build output directory: `/` (root).
6. Deploy to Preview first and test the page on mobile and desktop.
7. Promote to production only after the QA checklist is sufficiently complete.
