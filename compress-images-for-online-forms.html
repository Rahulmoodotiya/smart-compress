Compress Images for Online Forms

Many online forms have their own file-size, file-type and image-dimension requirements. If a photo or scanned image is rejected because it is too large, resize or compress a copy and check it carefully before uploading.

First, check the form's upload rules

  • Maximum file size (for example, a limit stated in KB or MB).
  • Accepted formats—some forms allow only JPG/JPEG or PNG.
  • Required width, height, aspect ratio or photo dimensions.
  • Whether the form requires a color image, readable document scan or a specific background.

Requirements vary by website and application. Do not assume a universal size limit.

How to make an image smaller

  1. Keep a copy of the original image.
  2. Open SmartCompress and add your JPG, PNG or WebP image.
  3. Choose the output format requested by the form.
  4. Reduce the dimensions if the form specifies pixel sizes or if the original is unnecessarily large.
  5. For JPG or WebP, adjust quality gradually to reduce file size while keeping details readable.
  6. Download the result and confirm its file size and dimensions.

Photo versus document scan

For photographs, moderate compression may be acceptable if facial details, colors and edges remain clear. For scanned documents, signatures, certificates or text, prioritize legibility. A smaller file is not useful if letters or fine details become blurred.

Which format should you use?

  • JPG/JPEG: common for photographs and often required by upload portals.
  • PNG: useful for sharp graphics and images with transparency; it may be larger than JPG for photos.
  • WebP: can produce compact files, but only use it if the form accepts WebP.

When a file still will not fit

  • Try reducing the pixel dimensions, not just the quality.
  • For a photograph, switch to JPG if the portal accepts it.
  • For a text-heavy scan, try a reasonable JPG setting or reduce dimensions only enough to keep text readable.
  • Check whether the website has separate requirements for each upload field.
